## Conventions used in these docs

- Anything marked **[verify]** is a claim not yet confirmed against a primary source or on the
  machine in question; confirm before relying on it.
- Every measured number names the machine and the clip it came from.
- Targets are labelled as targets until a measurement replaces them.
